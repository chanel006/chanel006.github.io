Privacy policy

YT pipeline Drive · last updated 12 October 2026

What the tool is

YT pipeline Drive is a personal tool used only by its owner. It uploads the owner's own video files and their text files from the owner's own server to the owner's own Google Drive.

What data it accesses

  • Only the files and folders the tool itself creates in the owner's Google Drive (Google's drive.file permission). It cannot see any other file.
  • It does not read the owner's email, contacts, calendar or any other Google data.

What it stores and shares

  • The sign-in token Google issues is stored only on the owner's server, so uploads can continue.
  • No data is sold, shared with third parties or used for advertising.
  • The tool's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

How to remove access

The owner can remove the tool's access at any time at myaccount.google.com/permissions.
