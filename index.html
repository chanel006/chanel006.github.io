YT pipeline Drive

YT pipeline Drive is a personal tool. It copies finished videos, thumbnails and their text files from the owner's own production server to the owner's own Google Drive, so they can be reviewed and published.

It is used only by its owner. It is not offered to the public and has no other users.

It uses the Google Drive permission that only covers files the tool itself creates (drive.file). It cannot see, read or change any other file in the Drive.
